A diagram Modulo can read





Use a single-page diagram with separate shapes, legible text, and visible arrowheads. Digital exports are easiest to read. Photographs and hand-drawn diagrams are supported, but lighting, perspective, paper texture, and handwriting increase the risk of an incorrect interpretation.




Terminal: rounded rectangle or oval


Use for Start and End. Modulo accepts either common terminal style.


Rectangle


A safe assignment such as total = total + n.


Parallelogram



Input n:int or Output total.


Diamond


A condition such as n > 0?. Two outgoing arrows, labeled Yes and No.


Hexagon


A preparation or iteration header such as WHILE n > 0 or FOR i IN range(5); it is not treated as a condition diamond.


Small circle


Exactly two circles with the same connector label.




If recognition is uncertain, fix the source and upload again. Modulo does not guess missing directions or labels.


Recognition details: Each recognized element lists its original OCR text, OpenCV shape classification, and Tesseract confidence so you can compare the result with the source diagram before approving it.
