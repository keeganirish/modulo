MODULO - ONE-CLICK INSTALL
==========================
1. Extract this whole zip somewhere (e.g. your Downloads folder).
2. Double-click the installer for your system:
     Windows : "Install Modulo (Windows).bat"
     Mac     : "Install Modulo (Mac).command"   (right-click > Open the first time)
     Linux   : "Install Modulo (Linux).sh"
3. Wait a few minutes. It installs Python (if you don't have it), all required
   packages, and Tesseract OCR, then puts a "Modulo" icon on your desktop and
   starts the app.

macOS first run:
- If macOS says the installer or Modulo.app is from an unidentified developer,
  right-click it, choose Open, and confirm Open. This is required because the
  app is not code-signed or notarized.
- On Apple Silicon, the installer and desktop launcher force Python to run as
  arm64 so compiled packages such as NumPy and OpenCV use the same architecture.
- If the app cannot start, a startup dialog opens the log at
  ~/Library/Application Support/Modulo/modulo.log.

You only do this once. Afterwards just double-click the Modulo desktop icon.
You may see one Windows permission prompt (UAC) while Tesseract installs.

Uninstall: run "Uninstall Modulo (Windows).bat" (Mac/Linux: delete the Desktop icon and
the Modulo folder in Application Support / ~/.local/share).
Logs: install.log and modulo.log live in the Modulo install folder
(Windows: %LOCALAPPDATA%\Modulo).

The existing GitHub Actions / PyInstaller / Inno Setup files are still here if you
later want a single signed ModuloSetup.exe for distribution (see BUILD.md).
